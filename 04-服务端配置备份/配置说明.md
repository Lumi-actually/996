## 如何还原

把 `.dshbak` 去掉后缀覆盖回原位置即可，例如：

```powershell
Copy-Item "dbsrc.ini.dshbak" "D:\...\MirServer\DBServer\dbsrc.ini" -Force
```

改完配置必须重启对应进程，顺序是：

```
DBServer → (等 12s) → M2Server → (等 28s，加载到约 1000MB) → RunGate → (等 4s) → LoginGate
```

**必须用 WMI 启动**，否则进程会随工具调用被回收：

```powershell
Invoke-CimMethod -ClassName Win32_Process -MethodName Create -Arguments @{
  CommandLine = "`"<exe 完整路径>`""; CurrentDirectory = "<exe 所在目录>" }
```

## 数据库改动记录（无法用文件备份还原，需按此记录手工回滚）

| 改动 | 原值 | 现值 | 说明 |
|---|---|---|---|
| 库排序规则 | `SQL_Latin1_General_CP1_CI_AS` | `Chinese_PRC_CI_AS` | 修中文角色名乱码，108 个列同步修改 |
| 3 个索引列 | Latin1 | Chinese_PRC | `FLD_ACCOUNT` / `FLD_CHARACTER` / `FLD_REALACCOUNT`，需先删索引再改 |
| 角色 `舞萝卜` 名字 | 乱码 `???` | `舞萝卜` | 按 GBK 字节重写 |
| 角色 `舞萝卜` 删除标记 | `FLD_DELETED=1` | `0` | 角色列表才可见 |
| 角色 `老霍` | 等级 0、地图空 | 等级 1、地图 3 | 补全脏数据 |

回滚排序规则（**不建议**，会再次乱码）：

```sql
ALTER DATABASE [box] COLLATE SQL_Latin1_General_CP1_CI_AS;
```

## 环境依赖（重装时注意）

| 依赖 | 版本要求 | 备注 |
|---|---|---|
| SQL Server | 2019+ | 我们用 2025 Express（MSSQL17） |
| ODBC Driver | **必须 17** | Driver 18 强制加密会报 `certificate chain not trusted` |
| 防火墙 | 关闭或放行 7000/7110 | 我们直接关闭了全部配置文件 |

> `sqlcmd.exe` 依赖 ODBC 18，而 18 已卸载 → **sqlcmd 不可用**。
> 查库请用 PowerShell + `System.Data.Odbc` + `Driver={ODBC Driver 17 for SQL Server}`。

## 关键端口

| 进程 | 监听 | 作用 |
|---|---|---|
| DBServer | 7201 / 7301 | DB 网关 / 会话服务（唯一连 SQL 的进程） |
| M2Server | 7400 / 8400 | 游戏主逻辑 / DGate |
| LoginGate | **7000** | 登录网关（客户端第一跳，端口固定不可改） |
| RunGate | **7110** | 游戏网关（进游戏后第二跳） |
