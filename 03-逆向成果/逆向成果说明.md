## 二、Lua 明文（578 个文件）

客户端全部 mod 脚本的明文源码。获取方式不是解密，而是**在 LuaJIT 加载时从内存 dump**：

- APK 里那 1719 个加密 Lua 是**死数据**，从来没被读取过
- 客户端实际解密的是热更新下载的资源
- 所以在 `luaL_loadbuffer` 处 hook，直接把明文吐出来

**关键文件**：

| 文件 | 内容 |
|---|---|
| `34_139536.lua` | `ModuleChooseLayer` / `RespModSrvlist`，服务器列表与跳线逻辑 |
| `162_49962.lua` | `LoginProxy`，登录与建角流程、错误码表 |
| `17_65862.lua` | `GameEnvManager`，modlist 签名 key |
| `98_43851.lua` | `attTypeTable`，**属性索引语义表**（141 项，解属性数组必查） |
| `177_196860.lua` | UI 属性取值，含「饥饿」显示项 |

## 三、安卓补丁

| 文件 | 改了什么 |
|---|---|
| `RealNameActivity.smali` | `onCreate` 里插入 `finish()` + `return-void`，实名界面不再出现 |
| `LoginBean.smali` | `getAgeStatus()` 恒返回 `Integer.valueOf(1)` |
| `CQGameApplication.smali` | `onCreate` 顶部插入 `System.loadLibrary("gadget")` |
| `AndroidManifest.xml` | `<application>` 加 `android:extractNativeLibs="true"` |
| `libhook.js.txt` | 注入脚本本体（原文件名 `libhook.so`，实为纯文本 JS，靠后缀骗过 PM 解压规则） |
| `libgadget.config.json.txt` | Gadget 配置（原文件名 `libgadget.config.so`） |

### 注入脚本做了什么

1. hook `luaL_loadbuffer`，把每个 Lua chunk dump 到 `/sdcard/Android/data/com.fgcq.a143097/files/luadump/`
2. hook `xxtea_decrypt*`，把运行时密钥写进 `996key.txt`
3. **在内存中等长改写 Lua**，把服务器地址改成局域网 IP：
   ```
   v.srvip      = v.i or v.srvip        →  v.srvip      = "192.168.10.178"
   v.port       = v.p or v.port         →  v.port       = 7000
   v.proxyport  = v.x or v.proxyport    →  v.proxyport  = 7000
   ```
4. 另有一处针对游戏网关的补丁，把 `tonumber(proxyport or port)` 改成 `tonumber(7110)`

> **两个致命坑**（报告 §6.3 有详述）：
> `readUtf8String` 会做 UTF-8 解码导致下标≠字节偏移（Lua 里全是中文注释），
> 必须全程用 `Uint8Array` 按字节操作；`writeUtf8String` 会自动追加 `\0`，
> 必须用 `writeByteArray` 写等长字节。

## 六、如果需要继续改造

1. **先读** `文档\REVERSE-ENGINEERING-HANDOFF.md` 的 §11「已排除路线」——能省几个小时
2. 改服务端配置 → 按报告 §2.3 的顺序重启对应进程
3. 改安卓 APK → 按报告 §10 的命令重打包（约 4 分钟一轮）
4. 任何改动前先备份，命名规范 `原文件名.dshbak`
