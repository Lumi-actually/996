## 一句话结论

**PC 端不需要任何逆向**——服务端版本包里自带配套客户端，它的官方服务器列表本来就指向
`127.0.0.1:7000`，装上就能连本地服务端。
**安卓端需要逆向**——要绕过实名认证、绕过付费 SDK、把服务器地址改成局域网 IP。

## 快速上手

### 前提：服务端已启动

四个进程必须都在（顺序也重要）：

```
DBServer → M2Server → RunGate → LoginGate
```

端口：`DBServer 7201/7301`、`M2Server 7400/8400`、`LoginGate 7000`、`RunGate 7110`，
全部连 `127.0.0.1:1433` 的 SQL Server（库名 `box`）。

### PC 端玩法

1. 进入 `02-可直接运行的客户端\PC端-配套版本\`
2. 双击 `996M2_Client.exe`
3. 启动器里点「工具测试服1区」→ 等状态变好 → 点「启动」
4. 角色选择界面选人 → 进游戏

> **原理**：官方 modlist 是明文 JSON，其中 `serverData[0]` 就是
> `{"srvip":"127.0.0.1","port":"7000"}` —— 官方这个"工具测试服"本来就是给本地开发用的。

### 安卓端玩法

1. 手机安装 `02-可直接运行的客户端\安卓端\client-gadget-v14.apk`
2. 登录（需要真实可用的 996 账号，因为账号校验在官方 HTTP 接口上）
3. 直接进游戏（实名认证已被移除，服务器地址已改成局域网 IP）

> **注意**：这个 APK 里的服务器 IP 编译时写死为 `192.168.10.178`。
> 如果你换了网络，需要重新打包（见 `03-逆向成果\文档\` 里的说明）。

## 关键事实速查

| 项目 | 值 |
|---|---|
| 服务端引擎 | 996 M2（Delphi），来自 `version-pack.zip` 的 `新3端纯净版` |
| 数据库 | SQL Server，库 `box`，39 张表；**没有账号表**，登录不校验密码 |
| PC 客户端 | `996M2_Client.exe`，版本 3.40.1036 |
| 安卓客户端 | `com.fgcq.a143097`，版本 3.70.2001，Cocos2d-x + LuaJIT |
| 安卓重打包方式 | 免 root Frida Gadget 注入（无 root、无改机） |
| Lua 加密 | XXTEA（10 字节 sign + 密文），实际在内存中 dump 明文，无需解密 |
| 服务器列表 | **明文 JSON**（PC）；安卓走 SDK 下发 |

## 已验证/已排除

### ✅ 可用

- PC 端进游戏、移动、收发消息（实测角色在线）
- 安卓端过实名、进游戏、移动
- 中文角色名（数据库排序规则已修为 `Chinese_PRC_CI_AS`）

### ❌ 已排除的路线（别再试）

| 路线 | 结论 |
|---|---|
| x86 主机跑 arm64 模拟器 | 模拟器直接拒绝，绕过架构门后 QEMU 静默退出 |
| Frida 通过 adb 直连手机进程 | 未 root 无法 attach |
| Frida Java bridge | 该 gadget 构建在此机型不可用，一用就崩 |
| 暴力爆破 XXTEA 密钥 | 方向错误，APK 内的加密 Lua 是死数据 |
| 改 hosts 把官方域名指到本地 | 未 root 做不到 |
| `client-pc.rar` 里的 Delphi 演示版 | 2023 年构建，与服务端协议不匹配（登录首包只发 1 字节） |
| 修改 LoginGate 端口 | 引擎忽略 `Config.ini` 的 `GatePort` 和命令行参数，固定 7000 |
