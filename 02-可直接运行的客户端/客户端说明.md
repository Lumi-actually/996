# 可直接运行的客户端

两个客户端都已实测进入本地服务端，**不需要再改任何东西**。

---

## PC 端（推荐，零改造）

**位置**：`PC端-配套版本\996M2_Client.exe`

### 使用方法

1. 确保服务端四进程已启动（DBServer / M2Server / RunGate / LoginGate）
2. 双击 `996M2_Client.exe`
3. 启动器里点「工具测试服1区」，等状态从红变绿
4. 点「启动」
5. 角色选择界面选人 → 进游戏

### 为什么开箱即用

启动器读 `env.json` 里的 modlist 地址（`list.dhsf.xqhuyu.com`），
官方返回的服务器列表里写的地址就是：

```json
"serverData":[{
  "srvip": "127.0.0.1",
  "port": "7000",
  "srvname": "工具测试服1区",
  "state": "3"
}]
```

`127.0.0.1:7000` 正是本地 LoginGate，进游戏后连 RunGate `7110`，也是本地的。
**官方这个"工具测试服"本来就是给本地开发用的，所以一行配置都不用改。**

### `env.json` 内容（如需改动）

```json
{"channel":"1","gm":"0",
 "signkey":"634eff98723b31da43ed35f0dd4edf36",
 "modlist":"http://list.dhsf.xqhuyu.com/testmodlist/modlist_2002397226_1.txt"}
```

改 `modlist` 可以指向自己的列表服务器。注意格式是**两级**的：

```
第1级  <modlist URL>?type=getaway&time=..&sign=..
       → {"code":200,"data":["<真正的modlist地址>"],"msg":"..."}
第2级  <真正的modlist地址>
       → {"modData":[{"srvlist":"<服务器列表地址>"}], ...}
第3级  <服务器列表地址>
       → {"serverData":[{"srvip":"...","port":"..."}], ...}
```

> 三级都是**明文 JSON**，中文用 `\uXXXX` 转义（纯 ASCII）。
> 如果自己生成，务必用 `json.dumps(..., ensure_ascii=True)`，否则中文以原始
> UTF-8 字节写进去，客户端按 ASCII 解析会报「远端服务器配置格式异常」。

## 安卓端

**位置**：`安卓端\client-gadget-v14.apk`（147.8 MB）

### 使用方法

1. 手机安装（需允许未知来源）
2. 登录：**必须用真实可用的 996 账号**（账号校验在官方 HTTP 接口上，绕不掉）
3. 进入启动器 → 点「启动」→ 进游戏

### 这个 APK 改了什么

| 改动 | 目的 |
|---|---|
| `RealNameActivity` 的 `onCreate` 直接 `finish()` | 跳过实名认证界面 |
| `LoginBean.getAgeStatus()` 恒返回 1 | 让客户端认为是成年人 |
| `CQGameApplication.onCreate` 插入 `System.loadLibrary("gadget")` | 免 root 注入 Frida |
| 放入 `libgadget.so` / `libgadget.config.so` / `libhook.so` | Gadget 本体 + 配置 + 注入脚本 |
| `AndroidManifest.xml` 加 `extractNativeLibs="true"` | 否则 Gadget 加载不起来 |
| `libhook.so`（实为 JS 脚本）在内存中改 Lua | 服务器地址改成局域网 IP |

### 服务器地址写死在这里

`libhook.js.txt` 里的常量：

```javascript
const LOCAL_IP        = '192.168.10.178';
const LOCAL_PORT      = '7000';   // LoginGate
const LOCAL_GAME_PORT = '7110';   // RunGate
```

**换网络后必须重新打包**，否则连不上。重打包流程见 `03-逆向成果\文档\` 里的
`REVERSE-ENGINEERING-HANDOFF.md` §10。

### 登录账号

| 项 | 值 |
|---|---|
| 账号 | 你自己的 996 平台账号（我们验证时用的是官方注册的号） |
| 密码 | 同上 |

数据库里没有账号表，**游戏服不校验密码**；拦在客户端那一层的是官方 HTTP 接口。

## 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| PC 启动器线路一直红点 | 服务端没启动 / 7000 没监听 | 检查四进程，`netstat -ano | findstr :7000` |
| PC 点「启动」没反应 | 线路没变成绿色 | 先点线路条目，等状态刷新 |
| PC 进游戏角色列表为空 | 角色被标为已删除（`FLD_DELETED=1`） | 数据库改回 0 |
| PC 建新角色后等级 0、地图空 | `HUM_INFO_ADD` 不初始化字段 | 手工补全或改存储过程 |
| 安卓连不上 | IP 变了（APK 里写死） | 重新打包，或在同网段使用 192.168.10.x |
| 安卓登录报「用户名或密码错误」 | 账号不对 | 用真实 996 平台账号 |
